# Claude Overlay

Окно поверх всех программ. Говоришь «Клод, …» — он делает скриншот экрана и отвечает текстом.
Нажимаешь **F7**, когда на компьютере звучит вопрос (лекция, созвон, видео), — он распознаёт вопрос и подсказывает,
что ответить. **Окно не видно на демонстрации экрана** (Zoom, Teams, Discord, Google Meet, OBS, скриншоты) —
у тебя на мониторе оно видно как обычно.

Работает по твоей подписке claude.ai (Pro/Max) через Claude Code — API-ключ не нужен. Запросы тратят те же лимиты
подписки, что и обычный чат.

## Установка (Windows 10/11)

1. Распакуй папку куда удобно (например, на Рабочий стол).
2. Дважды кликни **`Установить.bat`**. Он сам поставит Python (если его нет), окружение и библиотеки —
   с прогрессом и понятными сообщениями. Первый раз — несколько минут.
3. Откроется **мастер настройки** — пройди шаги (каждый можно повторить):
   1. **Claude Code** — найдёт или установит его, уберёт старую сломанную копию из npm, поможет войти
      (`/login` аккаунтом claude.ai) и проверит вход пробным вопросом;
   2. **Конфликты настроек** — найдёт чужой адрес сервера или ключ в настройках Claude Code и в переменных среды
      Windows (из-за них бывает ошибка «401 User not found»), уберёт их с резервной копией;
   3. **Видеокарта** — если есть NVIDIA, докачает библиотеки CUDA (0,7–1,2 ГБ) и проверит работу;
   4. **Модели распознавания** — рекомендованные для твоего компьютера отмечены, скачивание с прогрессом;
   5. **Микрофон и звук компьютера** — индикаторы громкости, «скажи „Клод, привет“», «включи любое видео»;
   6. **Клавиши** — F7/F8/F9, можно переназначить нажатием;
   7. **Ярлыки** — «Claude Overlay» на рабочем столе и в «Пуске» (по желанию — запуск вместе с Windows).
4. Дальше запускай ярлыком **«Claude Overlay»** — без чёрного окна консоли.

Повторный запуск `Установить.bat` ничего не ломает — только доделывает, чего не хватает. Мастер можно открыть и потом:
⚙ → «Невидимость и система» → «Проверить и починить».

## Как пользоваться

| Говоришь / нажимаешь | Что происходит |
|---|---|
| «Клод, реши задачу на экране» | скриншот + ответ |
| «Клод, добавь, что без циклов» | дополнение к той же задаче (диалог продолжается) |
| сразу после ответа, 15 с | можно дополнять без слова «Клод» |
| «Клод» … пауза … вопрос | тоже работает |
| «Клод, следующее задание» | новый скриншот, прошлые условия помнит |
| «Клод, новая задача, …» | очистить диалог и начать заново |
| «Клод, без экрана, …» | вопрос без скриншота |
| «Клод, стоп» | прервать ответ |
| «Клод, вниз» / «вверх» | прокрутка |
| «Клод, скопируй код» / «скопируй» | в буфер обмена |
| «Клод, скрой» / «покажи» | спрятать / показать окно |
| «Клод, возьми текст из буфера» | добавить текст из буфера в материалы |
| «Клод, убери материалы» | убрать все материалы |
| **F7** | **вопрос со звука компьютера: нажать в начале вопроса и ещё раз в конце** |
| Esc (во время записи) | отменить запись |
| F8 | следующая фраза — команда без «Клод» |
| F9 | спрятать / показать окно |

Кнопки вверху окна: 📎 прикрепить файлы · 📋 текст из буфера · ⟲ новая задача · ⚙ настройки · ? справка ·
▭ компактный режим (только строка состояния; при ответе окно разворачивается само) · — спрятать · ✕ выход.
У каждого блока кода — «⧉ Копировать», под ответом — «⧉ Копировать ответ». Если пролистал вверх — внизу появится
кнопка ↓ «к последнему ответу». Окно таскается за верхнюю полоску, размер — уголком ◢; положение и размер
запоминаются.

## Невидимость на демонстрации экрана

Все окна программы (главное, настройки, мастер, справка, стандартное окно выбора файлов 📎, всплывающие сообщения)
спрятаны от захвата экрана. Собеседник в Zoom/Teams/Discord/Meet, запись OBS, «Ножницы», PrintScreen видят то, что
под окном, — а у тебя окно на месте. Внизу окна — «🛡 Скрыт от демонстрации экрана»; щёлкни по надписи (или
⚙ → «Невидимость и система» → «Проверить невидимость») — покажу снимок экрана таким, каким его видят на демонстрации.

- Кнопки окна на панели задач и в Alt+Tab нет. Значок в трее по умолчанию выключен (панель задач видна на
  демонстрации); включается в настройках.
- Курсор над окном — обычная стрелка: «рука» над пустым местом выдала бы окно.
- Свой скриншот для Claude окно больше не прячет — ничего не мигает.
- Нужна Windows 10 версии 2004 или новее. На более старой вместо окна на демонстрации будет чёрный прямоугольник —
  программа честно об этом пишет.

**Честно:** защита не спасает от камеры телефона, направленной на монитор, от некоторых программ удалённого
доступа (AnyDesk, TeamViewer и т. п.) и от очень старых драйверов захвата экрана.

## Вопрос со звука компьютера (F7)

1. Слышишь вопрос (лектор, собеседник в Zoom/Teams/Discord, видео) — жми **F7**. В запись попадают и **2 секунды
   до нажатия**: оверлей всё время держит в памяти последние ~2 минуты звука (никуда его не отправляя).
2. Вопрос закончился — **F7** ещё раз. Запись идёт ещё **1 секунду** и останавливается.
3. Весь кусок распознаётся точной моделью и уходит Claude вместе со скриншотом. Ответ:
   **Скажи:** одна-две простые фразы, и ниже, если нужно, «Если спросят подробнее» — 2–3 коротких пункта.

- Во время записи вверху: «🔴 Запись вопроса 0:05 ▮▮▮▮▯▯▯▯» — полоски показывают, что звук слышен.
- Слушаются все устройства вывода сразу (колонки, наушники, HDMI), берётся самое громкое. Переключил наушники —
  устройства переоткроются сами. Можно выбрать конкретное: ⚙ → «Звук».
- Модель: с видеокартой — `large-v3` (самая точная), без неё — `large-v3-turbo`. Пока нужная качается, F7 работает
  на уже скачанной и сама переключается. Выбрать другую — ⚙ → «Распознавание речи».
- F7, F8, F9 перехватываются целиком и не доходят до других программ.

## Материалы (📎)

Перед занятием прикрепи то, по чему будут спрашивать: лекции, конспект, методичку, вопросы или билеты.
**📎** — выбрать файлы, или **перетащи** их в окно; **📋** / Ctrl+V — текст из буфера. Подходят PDF, Word (.docx),
PowerPoint (.pptx), текст и картинки (сканы и картинки читает сам Claude). Старые .doc/.ppt — сохрани как
.docx/.pptx или PDF. Claude коротко расскажет, что понял, и дальше отвечает по ним; термины подсказываются
распознаванию речи. Материалы сохраняются между запусками; список, просмотр текста и удаление по одному —
⚙ → «Материалы».

### Конспект из чата с Claude

1. Открой **«Промпт для конспекта.txt»**, скопируй нужный вариант и отправь Claude в чате
   (вариант 1 — в конце чата; 2 — собрать по прошлым чатам; 3 — в начале нового чата).
2. Под ответом Claude нажми «Копировать», потом в оверлее — **📋**. Готово.

## Настройки ⚙

Всё, что раньше правилось в коде, — здесь; сохраняется в `workspace\settings.json` и применяется сразу.

- **Распознавание речи** — модели для команд и для F7, язык, подсказки-термины; таблица моделей: скачана или нет,
  размер, «Скачать» с прогрессом, «Удалить», «рекомендуем» по твоему железу; «Сравнить» — распознать последнюю
  запись F7 несколькими моделями и показать тексты рядом.
- **Звук** — микрофон и индикатор, чувствительность, слова-обращения, устройства для F7 с индикаторами, сколько
  секунд до/после нажатия F7.
- **Claude** — подписка или API-ключ, модели (sonnet / opus / haiku), «сколько думать», стиль ответа на F7,
  «как в тетради», формулы, скриншот к вопросу; для продвинутых — свои инструкции с кнопкой «Вернуть как было».
- **Клавиши** — переназначение нажатием, проверка конфликтов.
- **Внешний вид** — шрифт, размер, прозрачность, тема, компактный режим.
- **Материалы** — список, просмотр текста, удаление.
- **Невидимость и система** — статус и проверка невидимости, трей, автозапуск, журнал, диагностика (Claude Code
  и вход, видеокарта, модели, устройства звука), «Проверить и починить».

## Если что-то не так

- **Ошибка «401» / «User not found» / про вход** — мастер, шаги 1–2 («Открыть окно входа», «Конфликты настроек»).
- **Не слышит «Клод»** — ⚙ → «Звук»: проверь микрофон по индикатору, добавь в «Слова-обращения», как он тебя слышит
  (серая строка «(не мне) …» в окне), подвинь «Чувствительность».
- **F7: «компьютер не играл звук»** — ⚙ → «Звук» → «Откуда брать звук»: включи видео и посмотри, у какого устройства
  двигается полоска.
- **Медленно распознаёт** — мастер, шаг «Видеокарта»; без NVIDIA — модель полегче (⚙ → «Распознавание речи»).
- **Всё остальное** — ⚙ → «Невидимость и система» → «Открыть журнал» (`workspace\overlay.log`) и «Диагностика».

## Удаление

`Удалить.bat` — уберёт ярлыки и окружение `.venv`; по твоему выбору — скачанные модели и папку `workspace`
(материалы, настройки, журнал).

## Приватность

Голос и звук компьютера распознаются локально и никуда не уходят. Claude получает только распознанный текст вопроса,
скриншот и твои материалы — когда ты обращаешься к «Клоду» или нажимаешь F7. В журнал (`workspace\overlay.log`, только
на твоём компьютере) пишутся служебные сообщения, текст команд «Клод, …» и распознанных вопросов F7 — без ответов
Claude и без остальной речи с микрофона. Ключи и токены нигде не показываются.

## Для разработчиков

- `start.bat` — запуск с консолью (видно журнал); `python overlay.py --wizard` — мастер, `--settings` — сразу настройки.
- Код — в папке `app/` (устройство описано в `CLAUDE.md`), значения настроек по умолчанию — `app/config.py`.
- Тесты: `.venv\Scripts\python.exe tests\test_overlay.py [--ui] [--whisper]`.
