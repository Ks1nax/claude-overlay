# Claude Overlay — как устроено

Голосовой помощник поверх всех окон для Windows. Пользователь — студент, говорит по-русски, не программист:
все тексты в интерфейсе и сообщения — на русском, простыми словами, без технических терминов.

## Что умеет

1. **«Клод, …» голосом** — микрофон слушается постоянно, фраза распознаётся локально (faster-whisper).
   Если она начинается со слова-обращения («Клод», «Клодик», «Cloud»…), делается скриншот монитора под курсором
   и вопрос уходит Claude. Ответ печатается в окне. Следующие «Клод, …» продолжают тот же диалог;
   15 секунд после ответа можно дополнять без «Клод».
2. **F7 — вопрос со звука компьютера** (лекция, созвон, видео). Звук всех устройств вывода постоянно лежит
   в памяти (~2 минуты, кольцевой буфер). F7 в начале вопроса → запись (в неё попадают и 2 секунды ДО нажатия),
   F7 в конце → ещё 1 секунда и весь кусок целиком распознаётся точной моделью и уходит Claude со скриншотом.
   Esc во время записи — отмена. Ответ в формате «**Скажи:** …» + «Если спросят подробнее: …».
3. **Материалы** (📎 файлы, 📋/Ctrl+V текст, перетаскивание в окно): PDF, Word, PowerPoint, текст, картинки.
   Текст материалов вклеивается в инструкцию для Claude; термины подсказываются распознаванию.
   Хранятся в `workspace/materials`, переживают перезапуск.
4. **Конспект из чата** — `Промпт для конспекта.txt` → ответ Claude → 📋 в оверлее.
5. **Невидимость на демонстрации экрана**: все окна программы исключены из захвата экрана
   (`SetWindowDisplayAffinity(WDA_EXCLUDEFROMCAPTURE)`), нет кнопки на панели задач и в Alt+Tab, без консоли.
6. **Окно настроек ⚙** (всё, что раньше было константами), **мастер первого запуска**, `Установить.bat`/`Удалить.bat`.
7. **Главное окно — на движке Edge (WebView2)**: карточки вопросов, формулы KaTeX, подсветка кода, кнопки
   уточнений, история и справка — панелями в самом окне. Окна настроек, мастера и выделения куска экрана — Tk.

## Файлы

- `overlay.py` — тонкая точка входа: журнал, один экземпляр, режимы `--wizard`, `--settings`, `--setup-gpu`,
  `--gpu-test` (отдельный процесс проверки видеокарты), `--make-shortcuts`.
- `app/` — программа:
  - `config.py` — пути и **настройки**: `DEFAULTS` (бывшие константы) + `workspace/settings.json` (в файле только
    отличия от умолчаний). `S.имя` — чтение, `S.update(...)` — запись + уведомление слушателей (`on_change`).
    `CLAUDE_OVERLAY_WORKDIR` — другая рабочая папка (тесты), `CLAUDE_OVERLAY_DEBUG_VISIBLE=1` — окна видны на
    скриншотах (только для проверки внешнего вида; в файл не сохраняется).
  - `winsys.py` — Windows: `CaptureGuard` (невидимость), окно-инструмент, `SingleInstance` (мьютекс + события
    Show/Quit), известные папки, ярлыки через PowerShell/WScript.Shell, журнал (`setup_log`: tee в
    `workspace/overlay.log`, под pythonw stderr C-библиотек тоже туда), `grab_monitor_of` для «Проверить невидимость».
  - `prompts.py` — `SYSTEM_PROMPT`, `LISTEN_PROMPT` (+ вариант «подробнее»), `ANALYZE_PROMPT`, `MATERIALS_INTRO`;
    свои тексты из настроек перекрывают стандартные.
  - `textfmt.py` — «Клод» (`split_wake`, слова из настроек), мусор Whisper, Markdown (`md_segments`, маркеры `CODE`
    для кнопок «Копировать»), формулы (`render_tex` через matplotlib mathtext, шрифт `cm`).
  - `screen.py` — скриншот (mss, монитор под курсором), `encode_image`.
  - `audio.py` — `Segmenter`, `Listener` (микрофон; `stop()` для смены устройства, `level` для индикатора,
    `tap` для проверки в мастере), `SystemAudio` (WASAPI loopback всех устройств, кольцевой буфер, `segment`,
    `device_levels`, `refresh_if_stale`), `prepare_audio`, wav для «Сравнить модели».
  - `stt.py` — каталог моделей `MODELS` (размеры — из HuggingFace, кэш `workspace/models_info.json`),
    `model_cached`/`download_with_progress`/`delete_model`, `hardware_info` (nvidia-smi), `recommend`,
    видеокарта (`setup_gpu(report)`, `gpu_selftest`, `gpu_libs_setup`), `load_whisper` под `_LOAD_LOCK`,
    `Transcriber` (микрофон, `request_model`), `ListenTranscriber` (F7, `request_model`, `compare`).
  - `claude.py` — `clean_env`, поиск `claude.exe`, `check_login`, `explain_error` (понятное «что делать»),
    `ClaudeSession` (постоянный `claude -p` stream-json для F7), `cli_ask` (разовый с `--resume`), `api_ask`,
    `claude_read_file` (сканы/картинки).
  - `providers.py` — другие провайдеры по ключу (OpenAI, Gemini, OpenRouter, DeepSeek, Groq, Mistral, xAI, Ollama,
    LM Studio, свой адрес): один клиент формата OpenAI Chat Completions на urllib (поток SSE), картинка — data:-URL
    (без «зрения» не передаётся), `list_models`, `check`, `explain`; ключи — `workspace/api_keys.json`.
    `S.backend`: subscription / api (Anthropic) / provider; история диалога для api и provider хранится в окне.
  - `history.py` — история между запусками: `workspace/history/ГГГГ-ММ-ДД.jsonl` (вопрос, ответ, способ: voice/text/f7/
    materials), `load(поиск)`, `export_markdown`; окно — `ui_dialogs.show_history`; выключается `S.history_save`.
  - `region.py` — `RegionPicker`: снимок монитора под курсором затемнённым на весь экран, рамка мышкой → кусок
    (`App.pending_shot`) уходит со следующим вопросом вместо всего экрана.
  - `materials.py` — извлечение текста и `Materials` (add/remove/text/clear), `material_terms` → hotwords.
  - `hotkeys.py` — `HotkeyManager` (хук pynput с `win32_event_filter`, сочетания с Ctrl/Alt/Shift, `capture_next`
    для переназначения нажатием), `problems` (повторы, буквы без модификатора, занятые клавиши).
  - `tray.py` — значок в трее (pystray), по умолчанию выключен.
  - `ui_theme.py` — 6 тем (`THEMES`: dark, midnight, black, warm, light, paper; внутри темы все цвета разные,
    без чистых #ffffff/#000000), `apply_theme` — смена темы на лету: старые цвета → новые по ключам палитры во всех

    `Toggle`, `Slider`, `Choice` (ttk.Combobox), `ThinScroll`, `ScrollFrame`, `Meter`, `Tooltip`.
  - `ui_main.py` — `App`: логика главного окна (команды, F7, материалы, скриншоты, история, компактный режим,

    Потоки: главный — цикл окна pywebview (`App.run` → `web.start`), «logic» — `_setup` (скрытый корень Tk для окон

  - `webwin.py` — главное окно на движке Edge (WebView2 через pywebview, `transparent=True`, без рамки, поверх всех):
    `WebWindow` (`send` — события пачками через `run_js` в отдельном потоке, `key` — заменить неотправленное;
    `set_rect`/`rect` — физические пиксели через SetWindowPos; перетаскивание/размер — свой цикл по мышке `track`;
    `_before_show` — стиль «инструмент» и невидимость в потоке окна до показа; перетащенные файлы — DOM-событие
    `drop` с `pywebviewFullPath`), `Bridge` — `pywebview.api.*` (всё пересылается в поток логики через `ui_q`),
    `missing()` — нет pywebview / WebView2 → понятное сообщение при запуске.
  - `web/` — интерфейс: `index.html`, `app.css` (цвета — переменные из темы, одно закругление `--r: 8px`),

    info/help/history/check-панели; Markdown — marked, формулы — KaTeX, код — highlight.js; всё лежит в `web/vendor`,
    значки — шрифт Google Material Symbols Rounded в `web/fonts`, без интернета).
  - `ui_settings.py` — окно настроек (7 вкладок), `ui_wizard.py` — мастер (7 шагов, `workspace/setup_state.json`),
    `ui_dialogs.py` — проверка невидимости, справка, просмотр текста, `setup_tools.py` — ярлыки, автозапуск,
    установка Claude Code (winget → install.ps1), npm-копия, конфликты настроек (с резервными копиями).
- `setup/` — установка: `install.ps1` (общая для EXE и .bat; в конце ставит Microsoft Edge WebView2, если его нет: Python 3.10–3.14 ищется через реестр Windows, лаунчер
  py, привычные папки; без tcl/tk не подходит; нет подходящего — качает с python.org и ставит отдельный
  `…\Python312_ClaudeOverlay` без прав администратора; `.venv`; библиотеки; служебные строки `@@ШАГ` для EXE),

  `make_zip.py`, `make_bats.py`. Версия — `app/__init__.py: VERSION`.

  `Удалить.bat`, `start.bat` (запуск с консолью для отладки), `requirements.txt`, `README.md`,

- `Zip/claude_overlay.zip` — архив для друзей (без `.venv`, `workspace`, `tests`).

## Как вызывается Claude Code

```
claude -p --input-format stream-json --output-format stream-json --verbose --include-partial-messages
       --system-prompt-file <файл> --tools "" --strict-mcp-config --no-session-persistence
       --model sonnet --effort low
```
- Сообщения пишутся в stdin построчно: `{"type":"user","message":{"role":"user","content":[…]}}`, картинки — блоки
  `{"type":"image","source":{"type":"base64",…}}`. Один процесс отвечает на много сообщений подряд; конец ответа —
  `{"type":"result"}`. Текст — `stream_event` → `content_block_delta` → `text_delta`.
- Работает по подписке Pro/Max, API-ключ не нужен. `--effort` передаём явно (у пользователя `effortLevel: xhigh`).
- Измерено: первые слова ответа ~1 с, полный короткий ответ 2–3 с (F7 целиком: 1,1 с распознавание + 2,3 с ответ).
- Проверка входа: `claude -p "ответь одним словом: ок" --output-format json` → без входа `Not logged in · Please run /login`.

## Решения, которые нельзя ломать (и почему)

- **F7 — ручной режим** (нажал в начале и в конце). Автоматическое прослушивание убрано по просьбе пользователя.
- **Окно не листается само**: новый вопрос встаёт в верх ленты (`app.js`: `toLast`, снизу — распорка `#spacer`,
  чтобы было куда подняться), ответ дописывается ниже; колёсико/полоса прокрутки/клавиши → `st.follow=false`,
  позиция сохраняется, появляется стрелка «к последнему ответу». Проверяет `test_web_window`.
- **Ответы на F7 — простые**: «Скажи:» 1–2 фразы до 30 слов. Проверено на живом Claude.
- **Модели Whisper грузятся строго по очереди** (`_LOAD_LOCK`, сначала микрофон, потом F7), импорт faster-whisper —
  под `_IMPORT_LOCK` (иначе `_DeadlockError`).
- **Короткие записи F7 — без VAD** (фильтр тишины выкидывал тихую речь целиком).
- **Проверка видеокарты — в отдельном процессе**; **cuDNN — ровно той версии, что `cudnn64_9.dll` в ctranslate2**
  (проверено с нуля на копии: ctranslate2 4.8.5 → nvidia-cudnn-cu12 9.10.2.21).
- **Подсказка распознаванию команд не должна кончаться на «Клод,»** (`stt.WAKE_PROMPT`): со старой подсказкой
  `initial_prompt="Клод,"` Whisper выкидывал «Клод» из текста — на 10 озвученных командах узнано 0 из 10, сейчас 9 из 10.
- **Невидимость**: `-toolwindow` ставить ДО `overrideredirect` и `-alpha` (иначе Tk при смене прозрачности сбрасывает
  WS_EX_TOOLWINDOW и окно вылезает на панель задач — так было раньше после каждого скриншота). Окна создаются
  скрытыми (`withdraw`), защищаются, потом показываются. Tk пересоздаёт обёртку окна при смене overrideredirect/
  -toolwindow — affinity слетает; поэтому `CaptureGuard`: хук `SetWinEventHook(EVENT_OBJECT_CREATE…SHOW)` в главном
  потоке Tk (защищает и стандартный диалог файлов, и messagebox, и выпадающие списки в момент создания) + проход по
  окнам процесса раз в 0,5 с. Курсор над окнами — стрелка (`ui_theme.hand()`, в новом окне — `html.protect`),
  «рука», «I» и стрелки размера выдали бы окно.
- **Главное окно (WebView2) и невидимость**: хук `CaptureGuard` стоит в потоке «logic», а окно создаёт поток .NET.
  В хуке НЕЛЬЗЯ трогать стиль окна и звать `GetWindowText` для окна чужого потока: обмен сообщениями с потоком
  окна, который в этот момент ждёт поток логики, — взаимное зависание (так и было: окно пустое, логика стоит).
  Поэтому: заголовок — `InternalGetWindowText`; стиль «инструмент» + affinity — в `_before_show` (pywebview зовёт
  его синхронно в потоке окна до показа), потом проход раз в 0,5 с (`guard.tool_check`). Проверено: BitBlt, DXGI,
  Windows.Graphics.Capture — окна нет (0 % метки против 99 % без защиты), affinity 0x11 сохраняется после смены
  размера; кнопки на панели задач и в Alt+Tab нет.
- **Свой скриншот не прячет окно**, если `guard.fully_hidden()`; иначе (старая Windows) — прячет через прозрачность.
- **Микрофон по имени открывается сначала через MME** (как раньше), потом WASAPI с пересчётом частоты: на VB-Cable
  WASAPI-поток открывался, но отдавал тишину.
- **Win+D / «свернуть все»** сворачивает и окно без рамки — `web.unminimize()` раз в 0,25 с разворачивает.
- У `threading.Thread` есть своё свойство `name` — в потоках имя модели хранить в `model_name`.
- **Найдено линией проверки и исправлено** (не возвращать): Esc отменял запись только один раз (отпускание
  залипало в `pressed`, тест `test_hotkey_hook_esc_repeat`); остановка `ClaudeSession` во время ответа оставляла
  «Думаю…» навсегда — `stop()` шлёт `("interrupted", rid)`; «Авто» для F7 = `recommend()` (раньше не совпадало с
  «рекомендуем»); события Show/Quit создаются сразу в `SingleInstance.__init__`, вторая копия ждёт до 6 с и
  выходит; смена модели команд — в отдельном потоке, фразы во время загрузки не выполняются задним числом;
  сеть (размеры моделей HF) — только в рабочих потоках (`cached_sizes` в окне); полоса прокрутки тоже ставит
  `follow=False`; `config.normalize` — типы и пределы значений из settings.json; `SystemAudio` открывается строго
  по одному, секунды до/после меняются без переоткрытия (`update_keep`); мастер, открытый из оверлея, при закрытии
  возвращает оверлей; ссылки «Копировать» привязываются к тегу один раз; F7 в режиме API — с инструкцией «Скажи:»;
  тайм-аут установщика — в фоновом потоке; `Удалить.bat` — ответы цифрами (Y/N не работают в русской раскладке),
  убирает только ярлыки своей папки.
- **Окно при запуске пустое**: приветствия нет — подсказки в меню шестерёнки («Как пользоваться», `toggle_info` →
  панель под заголовком, прячется щелчком в окне), служебные сообщения запуска — только в журнал.
- **Интерфейс 2.5** (по просьбе пользователя): значки — Google Material Symbols Rounded; шаги «Слышу › Распознаю ›
  Думаю › Отвечаю» — только подсветка текста, без кружочков; у всех элементов одно закругление 8 px (как у окон
  Windows 11); карточки вопросов с миниатюрой скриншота; кнопки «Короче/Подробнее/Объясни проще/Пример»
  (`App.quick`); «Скажи:» в ответе F7 — отдельный блок (`decorate` в app.js); призрачный режим (`S.ghost`).
  Память окна ~500–650 МБ вместе с движком — пользователю не важно (сам сказал).
- **Вопрос текстом**: поле внизу (`#ask`, `S.text_input`), `submit_text(text)` → `command()` (команды работают).
  По горячей клавише окно делается активным через `winsys.force_foreground` и в поле ставится курсор (`web.focus`).
  Ctrl+V в поле — обычный, вне поля — в материалы. Клавиши: `hotkeys.ACTIONS` (listen, talk, toggle, region, type).
- **Формулы**: в главном окне — KaTeX (понимает и сокращённые `\frac52`, `\sqrt2`); формулы вынимаются из текста
  до Markdown (`renderMd` в app.js), не нарисовалась — показывается текстом. matplotlib (`textfmt.render_tex`,
  `fix_shorthand`, `tex_to_text`) остался для окон Tk.
- **Тема меняется без перезапуска**: окна Tk — цвета только из `T[...]`, свой элемент с рисованием — `retheme(cmap)`;
  главное окно — `retheme` шлёт палитру (`theme_vars`: ключи `T` → CSS-переменные), в CSS цвета только через `var(--…)`.
- Пользователь — на Windows 11 (сборка 26200), NVIDIA RTX 3070 Ti 8 ГБ + CUDA, VB-Cable и Virtual Audio Cable
  (браузеры на «Chrome out»/«Edge out»), наушники JBL, рабочий стол перенаправлен в OneDrive (ярлыки — через
  `known_folder`).

## Грабли, на которые уже наступали

- Старая сломанная копия Claude Code из npm (`%APPDATA%\npm\claude*`) перекрывала новую — мастер её находит.
- `%USERPROFILE%\.claude\settings.json` с блоком `env` (`ANTHROPIC_BASE_URL` OpenRouter + токен) → «401 User not found».
  Мастер находит и убирает с резервной копией; `clean_env` не передаёт эти переменные и переменные родительской
  сессии Claude Code (`CLAUDE_CODE_*`, кроме `GIT_BASH_PATH`/`OAUTH_TOKEN`/`MAX_OUTPUT_TOKENS`).
- `irm https://claude.ai/install.ps1 | iex` минутами молчит — мастер показывает «идёт установка… N с»; основной путь —
  `winget install -e --id Anthropic.ClaudeCode`.
- HuggingFace: `HF_HUB_DISABLE_XET=1` (прогресс по размеру файла), `HF_HUB_DISABLE_PROGRESS_BARS=1` (без консоли).
- F7 в браузере включает «режим каретки» — свои клавиши перехватываем целиком.
- Остановка потока PortAudio ждёт конца обработчика звука: нельзя держать `SystemAudio.lock` во время `stop_stream`.
- Venv-лаунчер `Scripts\python(w).exe` запускает дочерний процесс базового Python — PID окна ≠ PID лаунчера.
- Инструмент скриншотов computer-use сворачивает окна не из списка разрешённых — не путать с багом программы.
- Баг друга (2.3): .bat не находил стоящий Python 3.12 — путь с русскими буквами приходил из Python в другой
  кодировке. Поэтому установка — PowerShell + реестр. В PowerShell 5.1 нельзя `& python ... | Select-Object -First 1`:
  обрывает программу, код −1. Скрипты .ps1 — в UTF-8 с BOM (иначе 5.1 читает русский как ANSI).
- Проверка EXE: тихо `/VERYSILENT /DIR=… /TASKS=""` во временную папку → `unins000.exe /VERYSILENT`; ярлык
  «Пуска» с тем же именем у пользователя — сохранить и вернуть; оверлей пользователя может работать — не слать ему
  Quit (тестовая копия просто «будит» его и выходит).
- pywebview требует главный поток (`webview.start`), `run_js`/`evaluate_js` ждут ответа окна; tkinter работает и
  в другом потоке, если всё создаётся и вызывается в нём (поток «logic»).
- Проверки с `python -X utf8` роняют `test_installer_progress_parsing` (дочерний процесс печатает «█» в cp1251) —
  запускать без `-X utf8`, при выводе в файл — `PYTHONIOENCODING=utf-8`.
- **Не проигрывать тестовый звук в VB-Cable, когда пользователь в звонке**: «CABLE Output» может быть микрофоном
  в Discord/Zoom. Для проверки распознавания — wav-файлы (тесты `--whisper`).

## Как проверять

- `python -m pyflakes overlay.py app tests` — без ошибок.
- `.venv\Scripts\python.exe tests\test_overlay.py` — логика (настройки, «Клод», Markdown, формулы, клавиши,
  материалы всех форматов, звук, конфликты/npm на подставных файлах, модели); `--ui` — окна с заглушками
  (прозрачные, не забирают фокус): логика главного окна с подставным окном `FakeWeb` (команды, F7, материалы,
  компактный режим, текст, кусок экрана, темы, провайдер), настоящее окно на движке Edge `test_web_window`
  (формулы KaTeX, код, таблица, «не листается», «Скажи:», полоска, affinity 0x11, нет на панели задач), настройки
  (все вкладки, переназначение клавиш), справка, проверка невидимости, все шаги мастера; `--whisper` — настоящее
  распознавание озвученных команд.
- Невидимость снаружи: снять экран BitBlt (mss), DXGI (dxcam), Windows.Graphics.Capture (windows-capture) — в
  области окна не должно быть его цветов; `GetWindowDisplayAffinity` == 0x11; WS_EX_TOOLWINDOW.
- Установщик: копия папки во временную → `Установить.bat` → новый `.venv` → мастер (`.venv` пользователя не трогать).
- Пользователь читает только итог: что сделано, как проверено, что проверить не удалось. Без технической каши.
